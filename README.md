# StudyHub 2.0 — v0.10

Учебная платформа для 60 студентов четырёх групп. Бюджет пилота — 0.

## Посмотреть интерфейс

В архиве есть **preview.html** — демонстрация в одном файле. Откройте его в обычном браузере; внешний сервер не требуется. Если просмотрщик телефона не выполняет JavaScript, откройте файл в браузере либо используйте локальный запуск ниже.

Верхняя панель переключает демонстрационные роли. Данные сохраняются только в этом браузере; если браузер запрещает локальное хранение, они живут до перезагрузки. Пригласительные ссылки демонстрации работают только там, где сохранены эти данные. Не используйте демонстрацию для настоящих студентов.

## Локальный запуск

Публикация сайта через GitHub и Netlify: [инструкция](docs/netlify.md). Настройки сборки сохранены в `netlify.toml`; публичные параметры Supabase задаются в Netlify перед сборкой.

Node.js 24.15+ в ветке 24 (проверено на 24.19), npm:

```sh
npm ci
npm run dev
```

Откройте адрес, который покажет Vite. Без переменных окружения работает демонстрация.

```sh
npm test
npm run build
npm run build:preview
```

## Подключение Supabase позже

1. Создайте новый тестовый проект Supabase.
2. Примените SQL из supabase/migrations по порядку.
3. Отключите подтверждение email в настройках Auth для согласованного сценария.
4. Скопируйте .env.example в .env, задайте публичные VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY. Никогда не используйте service_role в браузере.
5. Зарегистрируйте собственный аккаунт. В доверенном SQL Editor добавьте его UUID в platform_owners. До этого аккаунт не является владельцем.
6. Перезапустите Vite. Проверьте сценарии на тестовых пользователях до реального запуска.

Публичный ключ не заменяет серверные права: чтение защищено RLS, изменения — проверенными RPC. Владелец не назначается из данных регистрации.

## Что работает на этом этапе

React + TypeScript + Vite; адаптивные формы входа и регистрации; обзор групп; создание группы и дисциплин; приглашения студентов, старост и преподавателей; принятие приглашения существующим аккаунтом; панель блокировок пользователей, групп и разделов; восстановление доступа; общая библиотека с загрузками, поиском, просмотром и удалением; разделы лекций, презентаций и материалов внутри дисциплин с текстом и файлами; задания с текстовыми условиями, сдача работ текстом и файлом, черновики и публикация оценок, возврат на доработку с историей попыток; расписание на выбранные семь дней и объявления группы с созданием, изменением и удалением; личные заметки с поиском и защитой от перезаписи устаревшей версии; Supabase-адаптер и отдельная локальная демонстрация; читалка PDF/TXT с позицией, закладками и личным избранным.

## Проверено

Сборка и TypeScript, пять тестов модели прав, девять миграций и контракты доступа в PGlite, девятнадцать тестов интерфейса и валидации в jsdom. jsdom проверяет взаимодействия, но не отображение CSS. Читалка PDF проверена в Chromium, включая мобильную ширину; полный визуальный аудит интерфейса, реальная Supabase Auth и загрузка байтов в Supabase Storage ещё не выполнены. Таблицы Storage в тестах имитируются.

## Ещё не реализовано

Повторяющиеся занятия и автоматические уведомления, остальные личные инструменты, ИИ и PWA. В интерфейсе пока нет смены ролей и полного отключения членства преподавателя. Перенос студентов, отзыв ссылок и снятие назначения дисциплины добавлены в v0.10. Восстановление пароля ещё не добавлено. Это этап разработки, не готовая платформа для публичного запуска.
