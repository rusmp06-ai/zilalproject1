# Ссылки и история браузера — v0.34

> Справка отдельного этапа. Версии и результаты проверок ниже относятся к моменту его разработки. Текущие настройки — в [README](../README.md) и [развёртывании](deployment-current.md), подтверждённые результаты — в [готовности пилота](pilot-readiness.md).

Открытый экран задаётся параметрами адреса, например:

- `/?view=library` — библиотека;
- `/?view=groups&course=ID&section=materials` — материалы дисциплины;
- `/?view=groups&course=ID&section=assignment&task=ID` — конкретное задание;
- `/?view=library&book=ID` — книга библиотеки.

Можно копировать адрес из браузера, сохранять закладку и открывать её после входа. Перезагрузка сохраняет раздел, дисциплину и её вкладку, выбранное задание или книгу. Позиция чтения продолжает сохраняться существующим механизмом читалки. В адрес не записываются ответ студента, имена, оценки и содержимое заметок. Для демонстрации дополнительно нужен `demo=1`; её данные существуют только в браузере, где созданы. Демоссылка на созданный файл не переносит этот файл на чужое устройство.

Переходы добавляют записи в историю. Повторное открытие того же адреса не создаёт лишнюю запись. Кнопки «Назад»/«Вперёд» восстанавливают экран. Перед уходом выполняется существующая защита черновиков: текст ответа немедленно сохраняется, незавершённая отправка блокирует переход, несохранённая заметка требует подтверждения. При отказе от перехода внутри приложения восстанавливаются прежние адрес и экран без удаления редактора. При уходе на другой документ или закрытии вкладки работает предупреждение браузера, где оно поддерживается; текст ответа сохраняется локально по правилам v0.32.

После загрузки аккаунта проверяются допустимость раздела и доступность дисциплины в его каталоге. Задание проверяется по каталогу выбранной дисциплины до чтения попыток, книга — по доступному каталогу библиотеки. Удалённый, скрытый или чужой ресурс не заменяется первым доступным. Показывается сообщение; можно вернуться к списку/главной или повторить открытие книги при ошибке сети. Серверные проверки прав остаются обязательными. Ссылка не выдаёт права доступа. Смена демонстрационной роли и выход из аккаунта возвращают на главную; старые записи истории также проходят проверки текущего аккаунта.

Параметры ссылок проверяются по допустимым значениям; неоднозначные повторения и неверные комбинации показывают недоступную страницу. Параметры приглашения и восстановления пароля во фрагменте адреса сохраняются при навигации; после принятия приглашения приложение переходит на главную. Не публикуйте ссылки с токенами приглашения или восстановления пароля как обычные учебные ссылки.

Область восстановления: основные разделы, студенческая дисциплина и её вкладки/задания, книга библиотеки. Выбранная дата расписания, фильтры, поисковая строка, прокрутка, открытый файл внутри дисциплины и внутренние панели администратора/преподавателя пока не сохраняются в адресе. Восстановление зависит от доступности аккаунта, существующих каталогов и их лимитов. Ошибка сети не считается доказательством удаления материала.

Ссылки используют параметры существующей страницы, поэтому дополнительных правил перенаправления Cloudflare Pages/Netlify не требуется. Новых миграций и ключей нет.

Проверки: `npm test`; `npm run test:navigation:browser` при запущенном dev-сервере на порту 5264 (или укажите `NAVIGATION_TEST_URL`). Проверяются перезагрузка раздела/вкладки/задания/книги, открытие ссылки во второй вкладке, история, отклонённый переход с восстановлением адреса, черновики ответов и заметок, недоступные цели и мобильный экран. Сценарий v0.32 `test:submission:draft:browser` также проверен с новой навигацией.

Собранная версия проверяется отдельно: `NAVIGATION_PRODUCTION_URL=http://127.0.0.1:4264/?demo=1 node tests/navigation-production.browser.mjs` при запущенном preview-сервере. Этот сценарий создаёт задание через интерфейс и не импортирует исходные модули в браузер. Прямое открытие `file://` в облачном Chromium запрещено его политикой; проверка файла preview.html выполняется через локальный HTTP-сервер.
