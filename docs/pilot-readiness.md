# Готовность пилота

Дата ревизии: 2026-10-17. Основной сценарий: вход → своя группа → дисциплина/материал → пара → задание → чтение/заметка. Пилот ограничен четырьмя группами и 60 студентами как стартовой нагрузкой, не техническим ограничением модели.

## Доказательства

| Проверка | Доказательство и граница |
|---|---|
| Модель прав и SQL | Локальные SQL-контракты PGlite; сравнение канонических миграций и повторного SQL Editor upgrade, включая RLS/ACL/триггеры. Это не снимок живой базы. |
| Интерфейс | jsdom и браузерные сценарии Chromium с настольными/мобильными ширинами. Это не физические телефоны. |
| Node | Полный набор проверяется на 22.22.2 и 24.19.0. Отчёты — test-results/node-*/unit-summary.json и CI. |
| Edge | Deno 2.7.1: авторизация, контекст, квоты, кэш, невалидные ответы Gemini и CORS. Google подменён тестовым транспортом; реальные токены Gemini не расходуются. |
| Реальный Auth/Storage | Исторические успешные проверки 11 октября описаны в архивном HANDOFF, разделах 15–17. Отдельный повтор текущей версии фиксируется ниже; история не доказывает работу всех последующих функций. |
| Настройки email | Read-only запрос /auth/v1/settings 17 октября подтвердил mailer_autoconfirm=false: подтверждение включено. Доставка нового письма этой проверкой не подтверждается. |
| Производительность | Бюджет стартового JS — 200 000 байт gzip, CSS — 35 000. Проверяется граф начальных импортов; PDF/OCR/оптимизатор не должны входить в него. Отдельный браузерный тест проверяет фактические запросы и офлайн-PDF. |

## Открытые условия допуска

- Регистрация нового студента с подтверждением почты и восстановление пароля на опубликованном адресе.
- Отдельные реальные аккаунты студента и преподавателя: отказ к чужим материалам и работам.
- Полный сценарий задания, загрузки, чтения и заметки на живой базе текущей версии.
- Неделя расписания и исключение на дату на живой базе.
- Физические Android/iOS, медленная сеть, перезагрузка/обрыв связи.
- Небольшая учебная группа: один реальный учебный день с записью замечаний.
- Сверка истории ручных SQL с историей CLI перед сменой способа миграций.
- Развёртывание нового CORS с точным ALLOWED_ORIGINS на edge.

Функции пилота не расширяются до закрытия этих пунктов. OCR, ИИ и оптимизация документов остаются дополнительными инструментами; их недоступность не должна мешать ручной публикации и учёбе.

## Журнал текущего повтора

Результаты записываются после выполнения. Наличие переменных и предыдущий успешный запуск не считаются новым пройденным тестом. Реквизиты аккаунтов, JWT, ключи и содержимое пользовательских документов сюда не записываются.

2026-10-17: `npm run test:course:sync` завершился успешно на живом Supabase. Две независимые сессии тестового аккаунта, чтение реальных байтов Storage второй сессией, двусторонние позиции/закладки, отказ устаревшей записи и удаление временного файла/отметок. Это вход существующего аккаунта, не регистрация нового студента и не доставка email. Пользовательские файлы не изменялись.

Итог сопровождения v0.46, 2026-10-17: 25/25 Node/SQL/UI-наборов на Node 22.22.2 и 24.19.0; 29/29 dev-сценариев Chromium после исправлений; 5/5 production-сценариев, включая офлайн-PDF; 9/9 Deno-тестов. Начальный JS: 165 993 байта gzip, CSS: 19 684; бюджет соблюдён. Prettier, генерация SQL и проверка текущей документации прошли. Отчёты локальны; новый удалённый CI должен запуститься после отправки коммита.

2026-10-17, v0.47: проверены снятие дневных/минутных квот и прежнего порога входных токенов, сохранение кеша и серверных прав, повтор миграции и равенство схем SQL-путей. 11 edge-тестов и 10 Node/SQL-тестов прошли.
