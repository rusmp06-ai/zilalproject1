# Кабинет преподавателя v0.28

Преподаватель начинает день с ближайшего занятия по своей дисциплине, очереди проверки и сохранённых черновиков оценок. Назначения преподавателя определяют доступ к курсам: одинаковые дисциплины разных групп показаны отдельными карточками. Если преподаватель также студент или староста, учебная главная сохраняется, а кабинет открывается через «Преподавание».

## Проверка и журнал

Очередь содержит последнюю попытку каждого студента по каждому заданию. Есть поиск, фильтры дисциплины и состояния, страницы и переход к следующей работе. Ответ и поддерживаемый файл можно читать рядом с оценкой. История попыток доступна отдельно; прежнюю попытку нельзя оценить вместо актуальной.

Черновая оценка видна преподавателям с правами проверки. Публикация явно подтверждается; опубликованную оценку можно исправить, но нельзя снова скрыть как черновик. Возврат требует комментария, после него студент сдаёт новую попытку. Собственную работу преподаватель не оценивает. История решений фиксирует автора, время и изменение балла; старые решения до этой версии не восстанавливаются искусственно.

Конфликт версий не перезаписывает чужие изменения. Локальный текст сохраняется, после обновления преподаватель явно переносит его в текущую версию либо принимает серверную. Черновики формы задания и проверки хранятся в текущей сессии браузера с разделением по аккаунтам и работам.

Журнал включает всех активных студентов и старост группы, в том числе не сдавших работу. CSV выгружает весь выбранный список, а не только открытую страницу; черновые баллы в экспорт не попадают. Изменение максимального балла после первой сдачи запрещено. Для новых сдач сохраняются условия задания на момент отправки; у прежних работ показываются текущие условия с соответствующей подписью.

## Подготовка занятий

В дисциплине доступны материалы, темы, задания и объявления. Расписание показывает собственные дисциплины, позволяет выбрать семь дней и открыть общее расписание группы. Сообщения групп доступны отдельно от публикации объявлений своим студентам.

## Обновление существующего проекта

Для базы с миграциями 001–015 выполните `supabase/StudyHub_update_v0.28.sql` в SQL Editor Supabase. Файл включает обновления 016, 017 и 018 в одной транзакции и допускает повторное выполнение. Для новой базы примените все миграции по порядку.

Обновите SQL и приложение вместе: старые прямые функции оценки закрыты, новый клиент использует проверку прав и версии через RPC. Архив не содержит настроек подключения; публичные `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` задаются перед сборкой. Для Cloudflare Pages: команда `npm run build`, каталог результата `dist`.

Проверки включают локальный PostgreSQL-контракт, права смешанных ролей, приватность черновиков, конфликт версий и браузерный сценарий от сдачи файла до публикации оценки. Подключённая база Supabase и опубликованный сайт требуют отдельной проверки после применения SQL и развёртывания.
