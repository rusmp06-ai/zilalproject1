# Личные заметки v0.8

> Справка отдельного этапа. Версии и результаты проверок ниже относятся к моменту его разработки. Текущие настройки — в [README](../README.md) и [развёртывании](deployment-current.md), подтверждённые результаты — в [готовности пилота](pilot-readiness.md).

Раздел «Мои заметки» доступен всем активным аккаунтам, включая преподавателей, старост и владельца. Каждый работает только со своими записями. Поддерживаются создание, редактирование, поиск по названию и тексту, удаление с подтверждением и страницы по 50 записей.

Название — до 200 символов, текст — до 50 000 символов. На аккаунт допускается до 1000 заметок и суммарно 1 МиБ UTF-8 текста с названиями. Лимит проверяется на сервере с блокировкой параллельных сохранений. Файлы, общий доступ, экспорт и автоматическое сохранение пока не добавлены.

Миграция 202610100007_private_notes.sql создаёт таблицу с RLS и RPC. Прямая запись клиентом запрещена. Владелец приложения не получает исключения для чужих заметок. Блокировка аккаунта закрывает чтение и изменение, снятие блокировки восстанавливает доступ без удаления данных. Блокировки учебных групп и дисциплин не затрагивают личные записи.

Версия записи проверяется при изменении и удалении: устаревшая вкладка не перезапишет свежие данные. При конфликте остаётся введённый текст; нужно обновить список и открыть актуальную заметку для сравнения.

Это защита доступа через приложение и клиентский API, без сквозного шифрования. Администратор инфраструктуры с привилегиями базы технически может прочитать данные. Тексты не включаются в аудит действий владельца.

Проверены RLS/RPC, скрытие чужих заметок от владельца, блокировка и восстановление, поиск, версии, пагинация и полный путь интерфейса в jsdom. Реальная Supabase Auth/Storage и визуальная проверка браузера ещё не выполнены. Демоверсия хранит записи в браузере, разделение ролей в ней предназначено для проверки сценариев и не обеспечивает настоящую конфиденциальность.
