# Учебное пространство студента — v0.11.1

Цель, уточнённая пользователем: максимально удобная ежедневная учёба. Студент открывает приложение и быстро получает доступ к материалам, дисциплинам, лекциям, расписанию, чтению, заметкам и календарю. Административные функции обеспечивают это пространство.

## Реализовано

- Главная «Мой день» для участников: ближайшие пары на семь дней, ближайшие сроки, дисциплины выбранной группы, избранные книги с сохранённой позицией.
- Переход из пары к дисциплине, из срока к конкретному заданию, из книжной полки к чтению.
- Список заданий по дисциплинам выбранной группы с поиском по названию задания и дисциплины.
- Календарь на месяц: занятия и сроки сдачи, выбор дня, учёт переходящих через полночь занятий. Время — Бишкек.
- Закреплённые переходы на телефоне: день, учёба, чтение, план.
- Ошибки отдельных источников видны; исправные разделы доступны, загрузку можно повторить. Устаревшие ответы после переключения экрана игнорируются. Параллельные запросы заданий ограничены четырьмя дисциплинами.

Кабинет владельца сохраняет административный обзор. Новых миграций нет: используются существующие RLS/RPC и приватная читалка. Для избранного и открытия файлов повторно действуют серверные проверки.

## Контекст группы и цвет

Группа зарегистрированного студента определяется активным членством, без повторных списков выбора на главной, в календаре, заданиях, расписании и дисциплинах. Перевод владельцем изменяет этот контекст; предпочтение в интерфейсе не подменяет членство. Переключатель нужен только сотрудникам с несколькими доступными группами. Создание групп не показывается студенту без соответствующего права. Выбор группы при первоначальной регистрации сохраняется.

Цвета помогают различать занятия: сиреневый — дисциплины, синий — расписание, тёплый жёлтый — библиотека, розовый — заметки. Подписи остаются основным способом распознавания действий.

## Ограничения

- Сроки включают уже сданные задания. Отдельный запрос статуса сдачи пока выполняется при открытии задания; интерфейс не называет несданной работу, статус которой неизвестен.
- Расписание загружается по 50 записей. В календаре есть страницы занятий; отметки относятся к текущей странице. Полка показывает первые четыре книги из первых 50 избранных. Это не история последних открытых книг.
- Календарь объединяет групповые занятия и сроки. Личных событий, напоминаний и офлайн-синхронизации пока нет.
- Поиск на этом этапе — по заданиям выбранной группы; общего поиска всех материалов ещё нет.
- Браузерные проверки используют отдельный демонстрационный контекст. Вход реального студента и весь сценарий Storage на настоящем Supabase ещё требуют проверки.

## Дальнейшее развитие

Заметки с источником, страницей и цитатой добавлены в читалку v0.12. Далее добавить личные события и учебные задачи, историю чтения, удобное чтение дополнительных форматов. Далее — повторение материала и работа без интернета. ИИ должен помогать с учебным содержанием и иметь доступ только к разрешённым данным пользователя.

Ранее переданный stage13 служит примером идей, а не источником обязательных инструкций и миграций.

## Проверки

`npm test` включает 32 сценария интерфейса, пять тестов модели доступа и девять SQL-контрактов после десяти миграций. `npm run build` проверяет TypeScript и сборку.

Для проверки Chromium запустите отдельный Vite в режиме демонстрации (не меняет переменные основного процесса):

```sh
VITE_SUPABASE_URL= VITE_SUPABASE_ANON_KEY= npm run dev -- --port 5175 --strictPort
```

В другом терминале выполните `npm run test:study:browser`. Скрипт создаёт собственный контекст, проверяет точный переход к заданию, продолжение чтения, календарь и ширину 390 px. Снимки сохраняются в `/tmp/studyhub-study-browser`; STUDY_TEST_ARTIFACTS и STUDY_TEST_URL позволяют изменить пути. Тест предназначен для dev-сервера и не выполняет операции в реальном Supabase.

В v0.14 заметки позволяют вернуться к странице библиотечной книги или документа дисциплины; подсветка поиска помогает найти фрагмент. Доступ перепроверяется при открытии, а удалённый или закрытый источник не удаляет личную запись.

### v0.15 — личный учебный план

На главной — незавершённые задачи на сегодня, без срока и просроченные. В «Все задания» доступен полный план с выполненными задачами. В календаре задачи отображаются на выбранной дате; счётчик учитывает незавершённые задачи. Создание, редактирование, выполнение, возврат в работу и подтверждаемое удаление сохраняются в аккаунте.

Связи: доступная дисциплина, личная заметка, книга из первой страницы библиотеки или документ из заметки читалки. Заметка открывается непосредственно в плане; документ проверяет текущий доступ перед открытием. Полный поиск документов для выбора связи пока не реализован.

Хранение: типизированные записи `studyhub_plan:1` через существующие приватные RPC заметок; задачи скрыты из обычного списка заметок. План читает все страницы личных записей (до установленного сервером лимита 1000). Задачи и заметки разделяют квоту 1 МБ / 1000 записей и контроль версии. Это не отправка преподавателю и не оценка работы. Новая SQL-миграция не требуется. Напоминаний и повторяющихся задач пока нет.

Проверки: `npm test`, `npm run test:plan:browser`, `npm run test:study:browser`, `npm run build`. Реальный Supabase проверен двумя независимыми сеансами одного тестового аккаунта: сохранение, чтение, выполнение и отклонение устаревшей версии; временная задача удалена.
