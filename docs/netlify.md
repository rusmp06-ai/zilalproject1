# Публикация в Netlify

> Справка отдельного этапа. Версии и результаты проверок ниже относятся к моменту его разработки. Текущие настройки — в [README](../README.md) и [развёртывании](deployment-current.md), подтверждённые результаты — в [готовности пилота](pilot-readiness.md).

В Netlify выберите Add new project → Import an existing project → GitHub → rusmp06-ai/zilalproject1, ветка main.

Настройки сборки находятся в netlify.toml: npm run build, каталог dist, Node.js 24. Netlify должен использовать Node.js не ниже 24.15.

До первой сборки добавьте переменные окружения для сборки сайта:

- VITE_SUPABASE_URL — URL проекта без /rest/v1/.
- VITE_SUPABASE_ANON_KEY — публичный ключ anon. Не используйте service_role.

Без этих переменных приложение запускается в демонстрационном режиме. Они встраиваются в браузерную сборку; после изменения требуется новый deploy. Секреты и пароли не хранятся в репозитории.

После публикации проверьте вход владельца, создание группы, регистрацию тестового студента, загрузку и чтение файлов. Укажите опубликованный адрес в Supabase Authentication → URL Configuration → Site URL. При использовании ссылок восстановления пароля также настройте разрешённые redirect URLs.

Публикация GitHub-репозитория сама по себе не создаёт сайт Netlify. Подключение выполняется пользователем в собственном аккаунте Netlify.
