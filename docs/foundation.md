Текущее состояние смотрите в README.md и library.md. Ниже сохранена запись первого этапа.

# Первый этап: фундамент

Создана начальная миграция для Supabase PostgreSQL: профили, владельцы, группы, членства, дисциплины, назначения преподавателей, приглашения, ограничения доступа, файлы, библиотека, учебный контент и аудит.

Все таблицы закрыты для anon/authenticated: RLS включён, клиентские права отозваны. Это безопасная заготовка, а не готовая система доступа. Пока не добавлены политики и серверные операции, приложение не сможет читать или менять эти таблицы.

Модель прав packages/shared/access.mjs проверена пятью тестами: node --test tests/access.test.mjs. Это проверки спецификации, а не интеграционные тесты RLS. SQL не запускался на PostgreSQL в этой среде и требует проверки перед применением.

Следующий этап: атомарное принятие приглашений с проверкой группы и дисциплин, создание группы старостой, назначение преподавателя, операции владельца и RLS. Затем React-интерфейс и подключение Auth. Политика приоритета групповых запретов пока предварительная.

Не реализованы: регистрация, загрузки, аудит через триггеры, интерфейс, задания и оценки, расписание, уведомления, ИИ и PWA. Миграция создаёт только основу модели, включая заготовку учебного контента.

При регистрации без подтверждения email нельзя доверять одному совпадению адреса для выдачи повышенных прав. Пока предлагается одноразовое секретное приглашение преподавателя, переданное старостой лично; точный механизм будет закреплён перед реализацией.
