# Оптимизация PDF v0.29

Выберите PDF в форме загрузки библиотеки, материала дисциплины или работы студента. Нажмите «Оптимизировать без потери качества». После успешной проверки показаны исходный размер, новый размер и процент экономии. Для загрузки выбран уменьшенный файл с прежним именем. До отправки можно вернуть оригинал. Файл на диске пользователя не изменяется.

Обработка происходит на устройстве, без передачи документа стороннему сервису. Оптимизатор перепаковывает объекты PDF в сжатые потоки объектов; содержимое изображений, шрифтов, страниц и метаданных не перекодируется. После записи проверяются байты и словари исходных потоков, число страниц, оглавление, извлечённый текст, размеры страниц и совпадение отображения каждой страницы при масштабе 1. Это проверка безопасности структурной перепаковки, а не сжатие фотографий со снижением качества.

Подписанные, зашифрованные, интерактивные документы, вложения, формы, аннотации, слои и структурированные документы для доступного чтения сохраняются без оптимизации. DOCX, PPTX, XLSX и EPUB уже используют архивную упаковку и пока не обрабатываются. Уже хорошо сжатый PDF может не уменьшиться: тогда остаётся оригинал.

Чтобы не перегружать телефон, обработка ограничена PDF до 20 МБ, 40 страницами, 4 млн пикселей на страницу, 40 млн пикселей на документ и минутой проверки. При ошибке, превышении лимита или отсутствии уменьшения используется оригинал. При смене выбранного файла старая обработка отменяется. Во время оптимизации отправка формы заблокирована.

Серверный лимит загрузки остаётся 10 МБ: оптимизация не обходит права, квоты и проверку формата. Сохранить документ большего исходного размера можно только если проверенный результат укладывается в лимит. Новый SQL не нужен; для существующего кабинета преподавателя по-прежнему требуется обновление базы v0.28.
