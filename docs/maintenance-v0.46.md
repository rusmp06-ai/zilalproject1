# Исправления по аудиту · v0.46.0

Дата: 2026-10-17. Изменения форматирования выделены в отдельный коммит 1996a5e; дальнейшие изменения поведения проверяются отдельно.

| Замечание | Результат |
|---|---|
| Код сжат в длинные строки | Prettier с закреплённой версией и проверкой CI. AppHeader/AppSidebar вынесены из App, страницы загружаются отдельно. В TS/TSX осталось 1 строка длиннее 200 символов вместо 714 до исправлений; это длинный литерал. |
| Два источника SQL | Только migrations содержат исходные определения. Исторические скачиваемые SQL сохранены как генерируемые файлы; точное совпадение проверяется. Полная цепочка и повторный накопительный upgrade дают одинаковую схему, включая права и RLS. |
| Устаревшая документация | Короткие текущие README/HANDOFF; прежние версии перенесены в docs/history. Подтверждение email включено; непройденные условия пилота перечислены явно. |
| Нет CI, тесты обрываются | GitHub Actions для Node 22/24, SQL, стиля, сборки, трафика, Chromium и Deno. Node runner выполняет все найденные наборы и формирует общий отчёт. Полный локальный запуск — npm run verify. |
| Тяжёлая загрузка | Начальный статический граф JavaScript: около 166 КБ gzip вместо 243 КБ. Бюджет 200 КБ закреплён проверкой. PDF/OCR/оптимизатор загружаются отдельно; обычное офлайн-сохранение не скачивает OCR/оптимизатор. |
| preview.html в Git | Удалён из отслеживания. Автономная демонстрация собирается отдельной командой без реквизитов Supabase и прикладывается CI как артефакт сборки. Команда работает также в Windows PowerShell. |
| Слишком широкий пилот | Новые функции приостановлены. Основной сценарий — учебные материалы, расписание, задания и чтение. Существующие таблицы и функции сохранены для совместимости и сохранности данных; это не сокращение схемы. |
| Wildcard CORS | В исходном коде заменён точным ALLOWED_ORIGINS и проверен тестами. На опубликованной edge-функции изменение появится только после настройки origins и её развёртывания. |
| Избыточный минимум Node | Поддерживается 22.22.2+, 24.15+ и 26+. Полные Node-наборы проходят на 22.22.2 и 24.19.0; production-сборка проверена на обеих ветках. |

Дополнительно исправлены гонка позднего ответа при переключении live → demo и обработка PDF workers в dev-режиме. Их выявили проверки текущей сборки. Браузерные тесты обновлены под сохранение маршрутов, новый недельный редактор и свёрнутые разделы главной страницы.

Размер PDF-модуля около 429 КБ, отдельного worker — 1,18 МБ; OCR core остаётся около 3,9 МБ по запросу. Уменьшение стартового графа не означает, что тяжёлые функции перестали требовать скачивания. Физический телефон и замер на реальной медленной сети остаются частью пилота.

Результаты автоматических и живых проверок, их границы и оставшиеся условия — в [pilot-readiness.md](pilot-readiness.md). Этот выпуск не добавляет миграций и не требует повторного SQL в уже обновлённой базе.
