# Дисциплины и материалы — v0.5

В разделе «Группы и дисциплины» кнопка «Открыть дисциплину» ведёт в её кабинет. Там три раздела: лекции, презентации, материалы. Все виды поддерживают текст/описание и необязательный файл до 10 МиБ. Форматы такие же, как в библиотеке.

Владелец управляет любым содержимым. Староста управляет материалами своей группы, назначенный преподаватель — назначенной дисциплины. Внутри курса они могут редактировать название и текст существующих материалов; для замены файла создаётся новый материал. Студент не редактирует и не удаляет публикации.

Материалы курса не являются публикациями общей библиотеки. Приватный бакет studyhub-courses проверяет доступ к конкретной дисциплине, её группе и разделу. Запрет библиотеки сам по себе не закрывает лекции; запрет лекций не закрывает презентации. Блокировка аккаунта/группы и запрет дисциплины закрывают соответствующий доступ.

Файлы библиотеки и дисциплин используют один бюджет в таблице storage_limits. Загрузка проходит резервирование, Storage API upload, проверку фактического размера/MIME из метаданных и публикацию. Неопубликованный файл доступен только управляющим курсом. Удаление выполняется через маркировку, Storage API remove и завершение в БД. Текстовые материалы удаляются одной RPC-операцией.

Каталог возвращает до 50 материалов на страницу. Текст отображается с экранированием React. Файлы PDF, текст и изображения открываются в браузере; офисные форматы скачиваются. Пока нет серверной конвертации, антивируса, сохранения прогресса чтения и версий файлов.

Все реализованные записи в БД журналируются. Демо хранит файлы локально и не синхронизирует пользователей. Структура таблиц Storage в тестах имитируется; настоящая загрузка байтов в Supabase требует отдельной проверки после подключения. Браузерная визуальная проверка пока не выполнена.

Проверки: студент не изменяет публикации; чужая группа не читает текст или объект; преподаватель не управляет неназначенным курсом; незавершённый файл скрыт от студента; ограничения разделов независимы; курс учитывается в общем бюджете; удаления убирают объект и записи.

Следующий этап: задания, сдача работ, проверка и оценки. Староста не получает право выдавать задания и оценивать без отдельного назначения преподавателем.
