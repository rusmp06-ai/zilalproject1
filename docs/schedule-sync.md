# Актуальность расписания — v0.33

> Справка отдельного этапа. Версии и результаты проверок ниже относятся к моменту его разработки. Текущие настройки — в [README](../README.md) и [развёртывании](deployment-current.md), подтверждённые результаты — в [готовности пилота](pilot-readiness.md).

Главная студента, учебный календарь и раздел расписания используют общий загрузчик. Полная выдача с пагинацией заменяет предыдущий набор: перенос, смена аудитории и удаление отменённой пары не оставляют старую запись на экране. Результат запроса для прежней группы или даты игнорируется после переключения.

Проверки происходят при открытии, возвращении фокуса/видимости, восстановлении соединения и раз в минуту в видимой вкладке. Скрытая вкладка не опрашивает сервер по таймеру. Это не push: изменение на другом устройстве может быть видно с задержкой до следующей успешной проверки. Изменения через форму расписания дополнительно рассылают сигнал в этой вкладке и через localStorage в другие вкладки. Без возможности хранения остаются опрос и проверка при возвращении.

Расписание обновляется независимо от заданий и библиотеки. Сохраняется проверенная копия с датой получения, аккаунтом, группой и границами периода. При сетевой ошибке или отключении сети можно показать только покрывающую выбранный период копию; главная допускает копию, покрывающую сегодняшний день. Она подписана «изменения не проверены», действия к материалам из главного блока заблокированы. Без подходящей копии показывается ошибка, а не сообщение об отсутствии занятий. Подтверждённый запрет доступа удаляет копии группы. Копии локальные, не гарантируют актуальность и исчезнут при очистке данных браузера.

«Сейчас» включает начало и исключает окончание занятия. В перерыве показывается ближайшая будущая пара, включая следующий день; после последней нет ложной следующей пары. Пересечения отмечаются предупреждением. Занятие через полночь учитывается в обоих днях. Все расчёты и подписи используют Бишкек (UTC+6). Дата «сегодня» переключается при смене дня; выбранная прошлая или будущая дата не сбрасывается.

Проверки: `npm test`, `npm run test:schedule:browser`, `npm run test:schedule:sync:browser` (dev-сервер, `SCHEDULE_TEST_URL` для другого порта). Браузерные сценарии проверяют опрос, возврат фокуса, смену аудитории, удаление, отключение/возврат сети, полночь, сохранение выбранной даты и мобильный экран. `test:day:offline:browser` проверяет собранное приложение с service worker. Для автономного открытия приложения нужен поддерживаемый браузер и успешная предварительная установка его оболочки; отдельная сохранённая копия расписания этого не гарантирует.

Новых миграций, ключей API и платных сервисов не требуется.
